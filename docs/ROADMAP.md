# 개발 범위와 다음 단계

## 현재 완료 범위

- 인증과 사용자 컨텍스트
- 워크스페이스 생성·조회·멤버 목록·소프트 삭제
- 워크스페이스별 개인 근무 컨텍스트 예외
- Slack형 1:1 DM 목록
- 메시지 조회와 전송
- 읽음 상태
- 사용자별 현지 시각 표현
- 이메일·공유 링크 초대와 멤버 합류
- 첨부파일과 예약 전송
- LangGraph 다단계 AI 검토·사용자 확정·공통 이해 카드
- 기한 조정·설명 요청·revision 재확인
- 합의 기록과 파일 근거 스냅샷

## 와이어프레임 확정 후 결정할 항목

1. 메시지 수신 갱신을 폴링으로 유지할지 WebSocket/STOMP 또는 SSE로 전환할지
2. 채널 UI가 필요해지는 경우 `DIRECT` 외 `CHANNEL` 대화 타입과 역할/권한 추가
3. 메시지 수정·삭제·답글·리액션 중 실제 화면에 들어갈 기능
4. 사용자 상태, 프로필 이미지, 최근 접속 시각의 필요 여부
5. AI 모델 품질·비용·응답 지연에 따른 작업 큐·비동기 처리 전환 여부

## MVP 이후 확장 후보

- WebSocket/SSE 실시간 갱신
- S3 호환 객체 저장소와 악성 파일 검사
- PDF 이미지 OCR과 파일별 정밀 근거 locator
- 채널·그룹 메시지와 다수 담당자
- 합의·파일 보존 기간 및 관리자 감사 정책
